制約・参照の補足

  • 会員カートとゲストカートの所有者は排他。carts.user_idとguest_cart_tokenの片方のみ設定。
  • 保存配送先・保存カードは会員ごとに最大1件。番号16桁は保持し、画面には下4桁のみ返却。
  • pending_merge_cart_idは任意の自己参照。ゲスト属性・所有権はバックエンドで確認。
  • cart_itemsの複合UKは(cart_id, product_id)、order_itemsは(order_id, line_number)。
  • 注文の商品名・価格・配送先・カード情報はスナップショット。保存情報へのFKは持たず、画像のみ現在の商品を参照。
  • 注文作成操作IDは必須・一意なFK。同一操作の注文は最大1件。
  • 日時はUTC保持・JST表示。ゲスト期限の起点や在庫処理方式等の未確定事項はDB設計書に従います。
