# SCA-06: ページ未検出画面

## 1. 基本情報

- **物理名:** `admin-not-found`
- **対象:** 管理者領域の未定義URLへアクセスした利用者。未ログイン・認証確認中・権限不足を含む。
- **利用環境:** PCブラウザ前提。スマートフォン専用レイアウトは対象外。
- **目的:** 存在しない管理者側URL・未定義ルートの案内と、認証・権限状態に応じた有効な画面への誘導。
- **遷移先:** SCA-02（商品管理一覧）、SCA-01（管理者ログイン）、SCA-07（権限不足）。CMN-03からSCA-04（注文履歴一覧）へも遷移可能。
- **共通画面:** CMN-03、CMN-04。
- **対象外:** ユーザー側未検出（SCU-10）、商品編集対象の不存在等（SCA-03のAE02）、注文詳細対象の不存在等（SCA-05のAD04）、各画面の通信・サーバーエラー。
- **記載範囲:** 配置、状態別表示、遷移、操作、文言、API連携。ルーティング・HTTPステータス・配信基盤のフォールバックは機能・インフラ設計で定義する。
- **文言:** 要件定義にも同じ文言を記載し、API設計時に表示条件との対応を確認する。文言IDはAPIコードではない。

## 2. 画面構成

### 2.1 共通枠

- 上部にCMN-03、本文末尾に静的フッターCMN-04を配置する。
- メインコンテンツはPC向けの中央パネルとする。ウィンドウ幅変更・文字拡大時に要素を重ねない。
- 権限確認済みの場合のみ業務ナビゲーションを表示する。商品管理・注文管理いずれも現在位置の強調は行わない。
- ショップへのリンクやカート情報は表示しない。

### 2.2 本文・導線

| 要素 | 表示・動作 |
| --- | --- |
| 見出し | 表示確定時にAN01「ページが見つかりません」。 |
| 管理者向け説明 | 権限確認済みの場合はAN02。 |
| 未ログイン向け説明 | 未ログイン・認証無効確定時はAN03。自動でログインへ転送しない。 |
| 商品管理一覧へ戻る | 権限確認済みの場合のみ表示。SCA-02の検索条件なし・先頭からの初期表示へ遷移。 |
| 管理者ログイン画面へ | 未ログイン・認証無効確定時のみ表示。以前の戻り先をリセットしてSCA-01へ遷移。 |
| 再読み込み | 認証・権限確認の通信失敗時にAN04と表示。認証・権限の再確認を実行する。 |

- 未定義URLのパス・パラメータを本文・通知にそのまま表示しない。ログイン後の戻り先としても使用しない。

### 2.3 操作性

- 初回の本文表示確定時に見出しへフォーカスを移す。初回確認失敗の場合はエラー見出し等に移す。
- タブ復帰や再確認のたびに見出しへフォーカスを移さず、操作位置を維持する。状態変化で操作要素が消えた場合のみ見出し等へ移す。
- 表示中のリンク・ボタンはキーボードで操作可能とする。
- 確認中・確認失敗・状態変化は支援技術でも認識可能にする。

## 3. 状態・遷移制御

### 3.1 認証・権限別の表示

| 状態 | CMN-03 | 本文・遷移 |
| --- | --- | --- |
| 初回確認中・復帰時の再確認中 | 非リンクのロゴと確認中表示。業務導線・管理者名は表示しない。 | 「確認中…」。権限未確認の業務導線は表示しない。 |
| 管理者権限確認済み | ロゴ、商品管理、注文管理、マスター管理者、ログアウト。 | AN01・AN02と「商品管理一覧へ戻る」。 |
| 未ログイン・認証無効確定 | 非リンクのロゴ。 | AN01・AN03と「管理者ログイン画面へ」。この画面に留まり、自動転送しない。 |
| 認証有効・管理者権限なし | 遷移まで非リンクのロゴとログアウト。 | SCA-07へ履歴置換で遷移する。 |
| 確認通信失敗 | 非リンクのロゴ。 | AN04と「再読み込み」。未ログインと断定しない。CMN-03のAH04と二重表示しない。 |

- SCA-06の状態制御を優先し、CMN-03の共通処理で未ログイン時に自動転送しない。
- SCA-07へ移動した後も同じ画面へのリダイレクトを繰り返さない。
- 確認結果は現在の管理者セッションに対応するものだけを採用する。離脱前・認証切替前の古い応答を反映しない。

### 3.2 他画面との境界

- 管理者領域の未定義ルートは本画面で扱う。
- 定義済み保護画面への未ログインアクセスは、各画面の仕様に従いSCA-01へ遷移する。
- SCA-03編集モードの商品ID不正・不存在・削除済みはAE02を同画面内に表示する。
- SCA-05の注文ID不正・不存在・未成立はAD04を同画面内に表示する。
- 通信障害・サーバーエラーを未検出として扱わない。
- ユーザー側未定義ルートはSCU-10で扱う。

### 3.3 操作抑止

- 本画面固有の未保存変更・更新操作はないため、AH05・AH06の離脱確認を行わない。
- 通常の認証確認・読み取り通信を理由に、本画面固有の重要処理フラグは設定しない。導線の表示は3.1に従う。
- ログアウト通信中・結果不明時はCMN-03の復旧・操作抑止を優先し、本文側の通常遷移も共通制御に従う。

## 4. アクション・イベント

### 4.1 初期表示・再読み込み・タブ復帰

1. CMN-03と管理者認証・権限確認を共有して実行する。重複した確認通信は省略する。
2. 結果に従い3.1の表示・遷移を行う。
3. 「再読み込み」での確認中は当該ボタンを非活性にし「確認中…」と表示する。失敗時はAN04を維持して再操作可能にする。
4. 復帰・再確認では2.3に従い不用意なフォーカス移動を行わない。

### 4.2 商品管理一覧へ戻る

- SCA-02の検索条件なし・先頭からの初期表示へ遷移する。

### 4.3 管理者ログイン画面へ

1. 以前の管理者ログイン戻り先情報をリセットする。
2. 未定義URL・SCA-06自体を戻り先として保持せず、ログイン後の遷移先をSCA-02とする。
3. SCA-01へ遷移する。期限切れと判別できる場合のみAL08を引き継ぐ。

### 4.4 共通ナビゲーション・ログアウト

- CMN-03の仕様に従う。ログアウト成功時は同共通仕様に従ってSCA-01へ遷移する。
- 管理者ログアウトによってユーザー側のセッション・カートを変更しない。

## 5. 状態・メッセージ一覧

| ID | 状態 | 文言・操作 |
| --- | --- | --- |
| AN01 | 未検出見出し | ページが見つかりません |
| AN02 | 管理者権限確認済み | お探しの管理画面ページは存在しないか、移動または削除されました。「商品管理一覧へ戻る」または上部メニューから移動してください。／「商品管理一覧へ戻る」 |
| AN03 | 未ログイン・認証無効 | お探しの管理画面ページは見つかりません。管理画面をご利用の場合は、管理者ログイン画面へ進んでください。／「管理者ログイン画面へ」 |
| AN04 | 認証・権限確認失敗 | 管理者のログイン状態を確認できませんでした。再読み込みしてください。／「再読み込み」 |

- 処理中：「確認中…」。期限切れ案内はSCA-01のAL08を使用する。
- 本文は状態に応じて表示を切り替え、確認失敗時にAN02・AN03のいずれかを推測して表示しない。

## 6. 画面で必要なAPI・共通連携項目

本画面固有の業務APIは設けない。CMN-03共通の管理者認証・権限確認を利用する。URL・メソッド・物理項目名・型・結果コードはAPI設計で確定する。

### 6.1 管理者認証・権限確認

| 方向 | 項目 | 用途 |
| --- | --- | --- |
| 送信・付随 | 管理者セッション情報 | 現在の管理者認証・権限確認。 |
| 受信 | 認証状態・管理者権限有無 | 本文・ヘッダーの切り替え、SCA-07遷移。 |
| 受信・認証時 | 管理者識別情報 | CMN-03とのセッション識別・状態同期。 |
| 受信 | 処理結果・エラー種別・判別可能な期限切れ | 確認失敗と未ログインの区別、AN04・AL08の判断。 |

### 6.2 画面間の共通連携（API通信なし）

| 情報 | 用途 |
| --- | --- |
| 共通認証・権限確認結果 | CMN-03との二重通信・二重通知を防止。 |
| 以前の管理者戻り先のリセット・ログイン後SCA-02への遷移指定 | 不正な戻り先や以前の戻り先を再利用しない。 |
| 期限切れ通知（判別時のみ） | SCA-01でAL08を表示。 |
| ログアウト処理状態・通常遷移許可 | CMN-03の処理中・結果不明時の制御に従う。 |
