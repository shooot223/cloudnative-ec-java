# SCA-03: 商品登録・編集画面

## 1. 基本情報

- **物理名:** `admin-product-edit`
- **対象:** 管理者権限確認済みの管理者。
- **利用環境:** PCブラウザ前提。スマートフォン専用レイアウトは対象外。
- **目的:** 商品の新規登録、または既存商品の編集（商品名・概要・詳細説明・税抜価格・在庫数・公開状態・販売設定、およびS3への商品画像アップロード・変更・解除）を行う。
- **遷移先:** SCA-02（商品管理一覧）、SCA-01（管理者ログイン）、SCA-07（権限不足）。
- **共通画面:** CMN-03、CMN-04。
- **対象外:** 本画面からの商品削除操作（SCA-02で行う）、複数画像の登録、画像のトリミング・加工編集、税率の商品別個別設定（共通税率を使用）、削除済み商品の編集・復元。
- **記載範囲:** 新規／編集モードの表示・入力制御、画像選択・S3アップロード・保存操作、未保存変更の離脱確認、競合・結果照会、文言、API連携項目。S3アップロード方式（署名付きURL方式またはAPI経由方式）や未使用画像のクリーンアップ、税額計算の端数処理規則は要件定義・機能設計で定義する。
- **文言:** 要件定義にも同じ文言を記載し、API設計時に表示条件との対応を確認する。文言IDはAPIコードではない。

## 2. 画面構成

### 2.1 共通枠・モード別タイトル・通知

- CMN-03の「商品管理」を現在の機能カテゴリとして表示し、本文末尾に静的フッターCMN-04を配置する。
- 新規登録モード（新規登録用ルート）のタイトルは「商品新規登録」、編集モード（編集用ルート・商品ID指定あり）のタイトルは「商品情報編集」とする。
- タイトルの下に、取得失敗、保存失敗、更新競合、結果不明等の全体通知領域を設ける。

- 新規／編集モードはルートで明示する。編集用ルートの商品IDが未指定・不正でも新規モードへ切り替えず、AE02を表示する。

### 2.2 フォーム構成

- 編集モードでは、上部に参照専用の基本管理情報（商品ID・登録日時・最終更新日時）を表示する。新規登録モードでは非表示とする。

| 項目 | 表示・入力仕様 |
| --- | --- |
| 商品ID（編集時のみ） | 参照専用で表示し、更新対象指定に使用する。 |
| 登録日時（編集時のみ） | APIの登録日時をJSTの「YYYY/MM/DD HH:mm」で参照表示する。 |
| 最終更新日時（編集時のみ） | APIの最終更新日時をJSTの「YYYY/MM/DD HH:mm」で参照表示する。 |
| 商品名 | 必須。ラベル付きテキスト入力欄。前後空白除去後1〜100文字（一覧・カードでの省略表示は各画面で行い、マスタは全文を保持する）。 |
| 商品概要 | 任意。ラベル付きテキスト入力欄（または複数行入力欄）。前後空白除去後200文字以内。未入力時は空（未設定）として保存する。 |
| 詳細説明 | 任意。ラベル付き複数行テキスト入力欄。前後空白除去後2,000文字以内。改行を保持する。 |
| 税抜価格 | 必須。ラベル付き数値入力欄。1〜9,999,999円の半角整数。 |
| 税込価格（参考・確認表示） | 入力中の税込価格プレビューは設けない。編集時のみ「現在登録されている税込価格」としてAPIの値を円単位・3桁区切りで表示する。税抜価格を変更しても保存前はこの値を更新しない。「税込価格は保存時に計算されます。」と案内する。 |
| 在庫数 | 必須。ラベル付き数値入力欄。0以上の整数（0〜99,999）。0の場合はユーザー側で「売り切れ」となる旨を案内する。 |
| 公開状態 | 必須。ラジオボタンまたは選択欄で「公開」「非公開」を選択する。新規登録時の初期値は「非公開」とする。 |
| 販売設定 | 必須。ラジオボタンまたは選択欄で「販売可能」「販売停止」を選択する。在庫数・公開状態とは独立して設定できる。新規登録時の初期値は「販売可能」とする。 |
| 商品画像 | 任意。画像ファイル選択、プレビュー表示、「画像を変更」「画像を解除（未設定にする）」操作を配置する。仕様は2.3に従う。 |
| 登録する／更新する | 新規モードでは「登録する」、編集モードでは「更新する」を表示する。 |
| 一覧へ戻る（キャンセル） | SCA-02へ遷移する。未保存変更がある場合は破棄確認（CMN-03のAH05と共通）を行う。 |
| 項目エラー領域 | 各入力欄の近くに検証エラーを表示する。 |

### 2.3 商品画像エリア

| 要素 | 表示・動作 |
| --- | --- |
| 現在の画像／選択画像プレビュー | 編集時は現在登録されている画像（未設定・取得失敗時はNo Image）を表示する。新しい画像ファイルを選択した場合は選択画像のプレビューを表示し、「未保存の画像変更あり」と分かるようにする。 |
| 画像ファイルを選択 | 許可された形式（JPEG / PNG / WebP）かつ上限サイズ（5MB以下＝5,242,880バイト以下）の画像ファイル1件を選択する。 |
| 選択を取り消す | 新規選択した画像を破棄し、編集開始時の画像状態へ戻す（選択中のみ表示）。 |
| 登録済み画像を解除 | 現在登録されている画像を「未設定（No Image）」に変更する指定を行う（既存画像がある場合のみ表示）。保存実行まで既存の確定状態自体は失わない。 |
| 画像解除を取り消す | 解除予定を取り消し、編集開始時の画像状態へ戻す。解除予定の場合に表示する。 |
| 画像エラー表示 | 形式不正、サイズ超過、画像読み込み失敗、S3アップロード失敗を画像エリア付近に表示する。 |

- 画像を選択・解除しただけでは商品の変更は確定せず、「登録する／更新する」による保存成立時に商品画像として反映する。保存フローの一環として画像をアップロードし、保存失敗・キャンセル時は既存商品の画像を置き換えない。

### 2.4 操作性・未保存変更の確認

- すべての入力欄、選択欄、ファイル選択、保存、戻る操作をキーボードで操作できるようにする。
- 日本語変換確定中のEnterや、単一行入力欄での意図しないEnter操作で即座に保存送信されないようにする。
- 初期表示値（編集時は取得した保存済み値、新規時は初期値）から1項目でも変更がある場合（画像の選択・解除を含む）は「未保存変更あり」として扱い、一覧へ戻る・CMN-03のナビゲーション・ログアウト実行時に破棄確認ダイアログ（AH05／AH06）を表示する。

## 3. アクセス・入力・操作制御

### 3.1 認証・対象商品制御

- 初回・復帰時はCMN-03と認証・権限確認を共有し、確認中はフォームや管理データを表示しない。
- 未ログイン・認証無効時はSCA-03（編集時は対象商品IDを含む）を戻り先としてSCA-01へ遷移する（期限切れはAL08）。権限不足時はSCA-07へ遷移する。
- 編集モードで商品IDが不正、または対象商品が存在しない・削除済みの場合はフォームを表示せず、AE02と「商品管理一覧へ戻る（SCA-02）」を表示する（SCA-06へは遷移しない）。

### 3.2 入力条件

| 項目 | 条件 | エラー文言ID |
| --- | --- | --- |
| 商品名 | 必須。前後空白除去後に1〜100文字。 | AE03・AE04 |
| 商品概要 | 任意。前後空白除去後に200文字以内。 | AE05 |
| 詳細説明 | 任意。前後空白除去後に2,000文字以内。 | AE06 |
| 税抜価格 | 必須。1〜9,999,999の半角整数（0円以下・負数・小数・数値以外は不可）。 | AE07・AE08 |
| 在庫数 | 必須。0〜99,999の半角整数（負数・小数・数値以外は不可）。 | AE09・AE10 |
| 公開状態 | 必須。「公開」「非公開」のいずれか。 | AE11 |
| 販売設定 | 必須。「販売可能」「販売停止」のいずれか。 | AE12 |
| 商品画像ファイル | 任意。形式：JPEG（`.jpg`/`.jpeg`）、PNG（`.png`）、WebP（`.webp`）。ファイルサイズ：5MB以下（5,242,880バイト以下）。壊れた画像でないこと。 | AE13・AE14・AE21 |

- 不正な入力や画像エラーがある場合は、S3アップロードおよび保存APIを呼び出さない。
- 数値項目は不正値を自動で切り捨て・0補完して送信しない。
- 商品名・概要・詳細説明に含まれる文字列はテキストとして扱い、HTMLを実行しない。

### 3.3 処理中の操作可否

| 状態 | フォーム入力・画像操作 | 登録／更新する | 一覧へ戻る | CMN-03の通常遷移・ログアウト |
| --- | --- | --- | --- | --- |
| 通常（未変更） | 可 | 新規は可、編集で変更なしは非活性 | 確認なしで可 | 確認なしで可 |
| 通常（未保存変更あり） | 可 | 可 | AH05で確認後に可 | AH05／AH06で確認後に可 |
| 初回商品取得中（編集時） | 非表示（ローディング） | 非表示 | 可 | 可 |
| 画像アップロード・保存通信中・結果照会中 | 非活性 | 非活性（「保存中…」） | 非活性 | 非活性（遷移抑止） |
| 保存結果不明（再確認待ち） | 非活性 | 非活性 | 非活性 | 非活性（結果確認のみ可） |

## 4. アクション・イベント

### 4.1 初期表示・再読み込み

1. 管理者認証・権限を確認する。確認失敗時はAE01と「再読み込み」を表示する。
2. 未解決の保存操作がある場合は、4.4の結果照会を優先する。
3. **新規登録モードの場合:**
   - 空のフォーム（公開状態＝非公開、販売設定＝販売可能）を表示する。
   - 保存操作識別情報を準備する。
4. **編集モードの場合:**
   - 商品IDを検証し、管理用商品詳細取得APIを呼び出してローディング表示を出す。
   - 取得成功時は各項目・現在の画像・最終更新日時・版情報を反映し、未変更状態としてフォームを表示する。
   - 対象商品が削除済み・不存在の場合はAE02と「商品管理一覧へ戻る（SCA-02）」を表示する。
   - 初回取得の通信失敗時はAE15と「再読み込み」「商品管理一覧へ戻る」を表示する。

### 4.2 画像選択・変更・解除

1. ファイル選択時に形式（JPEG/PNG/WebP）とファイルサイズ（5,242,880バイト以下）を検証する。
2. 不正なファイルの場合は選択を採用せずAE13・AE14・AE21を表示し、直前の有効な画像状態を維持する。不正選択を取り消すとエラーを解除し、その有効な状態で保存できる。
3. 有効なファイルの場合はプレビューを更新し、未保存変更ありの状態にする。
4. 「登録済み画像を解除」押下時はプレビューをNo Image（解除予定状態）に切り替え、未保存変更ありの状態にする。「画像解除を取り消す」で元に戻せる。
5. 画像選択・解除を含め初期値へ戻った場合は、他の変更がなければ未変更状態に戻す。プレビュー取得失敗だけで登録済み画像を解除しない。

- 既存画像・管理日時・税込価格の欠損や表示取得失敗は「取得できません」またはNo Imageとし、0や現在日時で補完しない。編集に必須の入力値・版情報が取得できない場合は保存不可とし再取得を案内する。

### 4.3 登録する／更新する

1. 文字列項目の前後空白を除去し、3.2の全項目検証を行う。エラーがある場合は通信せず、該当項目付近に表示して最初のエラー項目へフォーカスを移す。
2. 入力欄・画像操作・保存ボタン・戻るボタン・CMN-03の通常遷移を非活性にし、「保存中…」と表示する。
3. **新しい画像ファイルが選択されている場合（S3アップロード連携）:**
   - 機能設計で定める手順（署名付きURLの取得＋S3へのアップロード、またはAPI経由アップロード）に従い、画像のアップロードを実行する。
   - 画像アップロードが失敗確定した場合は、商品情報の保存APIを実行せず（既存商品の画像を壊さず）、AE16を表示して入力内容を保持したまま再試行可能にする。
   - アップロード結果不明時はAE23と「画像アップロード結果を確認」を表示し、保存APIを呼ばない。アップロード・検証完了を確認できた場合のみ、固定した入力内容で保存処理を続ける。未実行・失敗確定で再操作可能ならAE16を表示して操作を再開する。照会失敗・処理中は未確定状態を維持する。
4. **商品情報の登録・更新API実行:**
   - 操作識別情報、（編集時は）対象商品IDと確認時の版情報、各入力値、および画像指定（変更なし／新規アップロード済み画像識別子／画像解除）を送信する。
5. **成功時:**
   - 未保存変更フラグをクリアする。
   - 新規登録時はAP18（「商品を登録しました。」）、編集更新時はAP19（「商品情報を更新しました。」）の完了通知情報をSCA-02へ引き継ぎ、SCA-02へ遷移する（SCA-02側の4.4に従い一覧を再取得して通知を表示する）。
6. **編集時の更新競合（AP16相当）・削除済み判明時:**
   - 他での更新により版情報が不一致となった場合はAE17を表示する。入力内容を保持し、「最新の商品情報を読み込む」を案内する。注文等による在庫変更も競合に含める。
   - 最新情報の読み込み前にAE22で破棄確認し、同意後に取得する。成功した場合のみ入力・画像・版情報を置き換える。取得失敗時は入力を保持してAE15を表示する。自動マージは行わない。
   - 編集対象が既に削除され保存できないと確定した場合は、編集フォームを取り除いてAE02とSCA-02への導線を表示する。
7. **失敗確定時（項目エラー・システムエラー）:**
   - 項目エラーは該当項目付近、その他はAE18を全体通知に表示する。入力内容と選択画像状態を保持し、安全に再試行できるようにする。
8. **結果不明時（タイムアウト・通信切断等）:**
   - 自動で保存APIを再送せず、AE19を表示して4.4の結果照会へ進む。

### 4.4 保存結果照会・再開

- 保存APIの応答が確認できない場合は、元の操作識別情報で保存結果を照会する。未解決の間は重複登録・二重更新を防ぐため再送信を止め、「保存結果を確認」を表示する。

| 確認結果 | 表示・操作 |
| --- | --- |
| 当該保存の成功確定 | 未保存変更を解除し、AP18またはAP19を引き継いでSCA-02へ遷移する。 |
| 未実行・失敗確定かつ再操作可能 | AE18を表示し、入力内容を保持したまま通常操作・再試行を再開する。 |
| 当該保存が未実行・失敗確定、かつ編集対象が削除済み | AE02とSCA-02への導線を表示する。 |
| 処理中・結果不明・照会失敗 | AE19またはAE20と「保存結果を確認」を維持し、通常の保存再送・画面離脱を抑止する。 |

- 再読み込み・再訪問・再ログイン後も、未解決の保存操作があれば同じ操作識別情報で照会を再開できるようにする。

- 操作結果と商品の現在状態は別に扱う。対象が削除済みという情報だけで元の保存の成否を判定しない。保存成功後の削除と判明した場合も元の保存は成功として扱い、SCA-02では現在の一覧を再取得する。
- 再ログイン・再読み込み後は操作結果の確認を再開するが、破棄済みのフォームや選択ファイルの復元は保証しない。保存未実行・失敗確定後、入力が残っていなければ新規入力または最新情報の取得から再開する。
- 操作記録が見つからないことだけで未実行と判定せず、APIが再操作可能と確認できるまで重複送信しない。

### 4.5 一覧へ戻る・タブ復帰・ログアウト

- 「一覧へ戻る」押下時、未保存変更があればAH05で確認し、「変更を破棄して移動する」が選択された場合のみ入力を破棄してSCA-02へ戻る（SCA-02側の4.4に従い、実行済み検索条件・一覧を復元または再取得する）。
- タブ復帰時は認証・権限を確認する。編集中に入力途中のフォームを背景取得で勝手に上書きしない。
- ログアウト・認証無効・権限喪失時は入力キャッシュ・未保存データを破棄し、CMN-03の制御に従う。

- アプリ内の戻る操作は可能な範囲で未保存変更の確認対象とする。ブラウザ再読み込み・タブを閉じる操作ではブラウザ標準の離脱警告を可能な範囲で利用する。文言指定や表示・離脱阻止は保証しない。
- 結果不明時の操作抑止中も、認証無効・権限喪失時の必要な遷移は妨げない。ログアウト・入力破棄によってサーバー側の未解決操作記録は削除しない。
- 画面離脱後、対象商品変更前、認証切替前の古い応答で現在の画面を上書きしない。
- 読み込み・保存・エラーの状態変化を支援技術に通知する。確認ダイアログは取消側に初期フォーカスを置き、フォーカスを内部に保ち、取消時は元の操作へ戻す。

| AE08 | 税抜価格上限超過 | 税抜価格は9,999,999円以内で入力してください。 |
| AE09 | 在庫数未入力・形式不正 | 在庫数は0以上の整数で入力してください。 |
| AE10 | 在庫数上限超過 | 在庫数は99,999点以内で入力してください。 |
| AE11 | 公開状態未選択 | 公開状態を選択してください。 |
| AE12 | 販売設定未選択 | 販売設定を選択してください。 |
| AE13 | 画像ファイル形式不正 | 商品画像はJPEG、PNG、またはWebP形式のファイルを選択してください。 |
| AE14 | 画像ファイルサイズ超過 | 商品画像は5MB以下のファイルを選択してください。 |
| AE15 | 編集対象の初回取得失敗 | 商品情報の取得に失敗しました。再読み込みしてください。 |
| AE16 | 画像アップロード失敗 | 商品画像のアップロードに失敗しました。時間をおいて再度お試しください。 |
| AE17 | 更新競合 | この商品情報は他の操作によって更新されています。最新の内容を読み込んでから、再度編集してください。 |
| AE18 | 保存失敗確定 | 商品情報の保存に失敗しました。入力内容をご確認のうえ、再度お試しください。 |
| AE19 | 保存結果不明 | 商品情報の保存結果を確認できませんでした。「保存結果を確認」から結果をご確認ください。重複して登録・更新しないでください。 |
| AE20 | 保存処理中 | 商品情報の保存処理が進行中です。しばらくしてから保存結果を確認してください。 |
| AE21 | 画像読み込み・実体検証失敗 | 画像を読み込めませんでした。別の画像を選択してください。 |
| AE22 | 最新情報読み込み前の確認 | 未保存の変更を破棄して、最新の商品情報を読み込みますか？ |
| AE23 | 画像アップロード結果不明 | 商品画像のアップロード結果を確認できませんでした。「画像アップロード結果を確認」から結果をご確認ください。 |
| AE24 | 税込価格案内 | 税込価格は保存時に計算されます。 |

- 保存成功時の完了文言はSCA-02のAP18（「商品を登録しました。」）・AP19（「商品情報を更新しました。」）と共通化し、SCA-02へ遷移後に表示する。
- 未保存変更の破棄確認はCMN-03のAH05・AH06と共通化する。
- 操作ラベル：「登録する」「更新する」「一覧へ戻る」「画像ファイルを選択」「選択を取り消す」「登録済み画像を解除」「画像解除を取り消す」「画像アップロード結果を確認」「キャンセル」「変更を破棄して読み込む」「最新の商品情報を読み込む」「保存結果を確認」「再読み込み」。
- 処理中：「読み込み中…」「保存中…」「確認中…」。

## 6. 画面で必要なAPI・共通連携項目

以下は論理項目。URL・メソッド・物理名・型・結果コード、およびS3画像アップロードの具体的な通信手順（署名付きURL発行＋S3直接送信、またはマルチパート送信）は機能設計・API設計で確定する。

### 6.1 認証・権限確認（CMN-03共通）

| 方向 | 項目 | 用途 |
| --- | --- | --- |
| 送信・付随 | 管理者用セッション情報 | 管理者認証・権限確認。 |
| 受信 | 認証状態・管理者権限・管理者識別情報・処理結果・エラー種別 | フォーム表示、SCA-01・SCA-07への遷移、AE01表示。 |

### 6.2 管理用商品詳細取得（編集モード初期表示・競合時の最新再取得・SCA-02と共用可）

| 方向 | 項目 | 用途 |
| --- | --- | --- |
| 送信・付随 | 管理者用セッション情報 | 管理者参照権限の確認。 |
| 送信 | 商品ID | 取得対象商品の指定。 |
| 受信 | 処理結果・エラー種別・対象の有無 | フォーム表示、削除済み・不存在（AE02）、通信失敗（AE15）の区別。 |
| 受信 | 商品ID・商品名・商品概要・詳細説明 | フォームの初期値表示。 |
| 受信 | 税抜価格・税込価格 | 税抜価格の初期値設定、税込価格の参照表示。 |
| 受信 | 在庫数・公開状態・販売設定 | 各項目の初期値設定。 |
| 受信 | 現在の画像URL・画像設定有無 | 現在の画像プレビューと解除操作の表示制御。 |
| 受信 | 登録日時・最終更新日時・版情報 | 日時表示、更新時の競合検出。 |

### 6.3 商品画像アップロード（S3連携）

| 方向 | 項目 | 用途 |
| --- | --- | --- |
| 送信・付随 | 管理者用セッション情報 | アップロード権限の確認。 |
| 送信 | アップロード操作識別情報 | アップロード結果不明時の照会と再開。 |
| 送信 | ファイル名・MIMEタイプ・ファイルサイズ・画像バイナリ（方式はAPI設計で確定） | S3への画像格納と検証。 |
| 受信 | 処理結果・エラー種別 | 成功、形式・サイズ不正（AE13・AE14）、画像読み込み・実体検証失敗（AE21）、アップロード失敗（AE16）の判定。 |
| 受信・成功時 | アップロード済み画像の識別情報（S3オブジェクトキーまたは一時識別子）およびプレビュー参照情報 | 商品登録・更新APIへの引き渡し。 |

- アップロード結果照会：管理者セッション情報・元のアップロード操作識別情報を送信し、アップロード／検証状態、画像識別情報、再操作可否、処理結果を受信する。商品保存操作の結果照会とは区別する。具体的なエンドポイント分割はAPI設計で定義する。

### 6.4 商品新規登録・編集更新

| 方向 | 項目 | 用途 |
| --- | --- | --- |
| 送信・付随 | 管理者用セッション情報 | 登録・更新権限の確認。 |
| 送信 | 保存操作識別情報 | 二重登録・重複更新の防止、および結果不明時の照会。 |
| 送信・編集時のみ | 商品ID・確認時の版情報 | 更新対象の特定、注文等による在庫変更を含む競合検出。 |
| 送信 | 商品名・商品概要・詳細説明・税抜価格・在庫数・公開状態・販売設定 | 商品マスタの登録・更新。税込価格はバックエンドで算出する。 |
| 送信 | 画像更新区分（変更なし／新規画像適用／画像解除）およびアップロード済み画像識別情報 | 商品画像の関連付け・解除。 |
| 受信 | 処理結果・エラー種別・対象項目 | 成功、項目エラー、競合（AE17）、削除済み（AE02）、失敗確定（AE18）、処理中の区別。 |
| 受信・成功時 | 保存された商品ID・版情報・操作識別情報 | SCA-02への復帰と完了通知（AP18・AP19）の連携。 |

### 6.5 保存結果照会

| 方向 | 項目 | 用途 |
| --- | --- | --- |
| 送信・付随 | 管理者用セッション情報 | 結果参照権限の確認。 |
| 送信 | 元の保存操作識別情報・（編集時は）商品ID | タイムアウト等で結果不明となった保存要求の特定。 |
| 受信 | 当該操作の状態（成功確定／未実行・失敗確定／処理中／不明）・対象商品ID・再操作可否 | SCA-02への遷移、再試行再開、待機継続（AE19・AE20）の分岐。 |

### 6.6 画面間の連携（API通信なし）

| 情報 | 用途 |
| --- | --- |
| 新規／編集モード・対象商品ID・SCA-02の検索条件および復元情報 | SCA-02からの遷移と復帰。 |
| 保存完了通知（AP18／AP19）・保存された商品ID | SCA-02での再取得と通知表示。 |
| 未保存変更の有無・画像アップロード／保存通信中・結果不明・通常遷移許可 | CMN-03との離脱確認（AH05・AH06）および操作抑止の共有。 |
