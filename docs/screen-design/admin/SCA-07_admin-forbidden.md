# SCA-07: 権限不足画面

## 1. 基本情報

- **物理名:** `admin-forbidden`
- **対象:** 管理者側の認証は有効だが管理者権限を持たない利用者。直接アクセス時の未ログイン・権限確認済みの状態も制御する。
- **利用環境:** PCブラウザ前提。スマートフォン専用レイアウトは対象外。
- **目的:** 権限不足を通知し、権限再確認または管理者セッション終了を行う。
- **遷移先:** SCA-01（管理者ログイン）、SCA-02（権限確認済みの場合）。
- **共通画面:** CMN-03、CMN-04。
- **対象外:** 権限付与申請、アカウント追加、機能別ロール制御、一般会員側の認可エラー。
- **記載範囲:** 表示・操作・遷移・ログアウト復旧・文言・API連携。認証・権限検証やセッション終了の内部方式は共通認証・機能設計で定義する。
- **文言:** 要件定義にも記載し、API設計時に結果コード・表示条件との対応を確認する。文言IDはAPIコードではない。

## 2. 画面構成

### 2.1 共通枠

- 上部にCMN-03、本文末尾に静的フッターCMN-04を配置する。
- PC向けの中央パネルとし、文字拡大・ウィンドウ幅変更時に要素を重ねない。
- 権限不足時のヘッダーは非リンクのロゴと「ログアウト」のみ。業務ナビゲーション・マスター管理者表示・業務データは表示しない。

### 2.2 本文

| 要素 | 表示・動作 |
| --- | --- |
| 見出し | AB01「アクセス権限がありません」。権限不足確定時に表示。 |
| 説明 | AB02。内部のロール名・Cognitoグループ名・権限コードは表示しない。 |
| ログアウトして管理者ログイン画面へ | 主操作。CMN-03と共通の管理者ログアウトを実行する。成功後はSCA-01へ履歴置換。 |
| 権限を再確認 | 管理者認証・権限を再確認する。ログアウト開始前のみ利用可能。 |
| 再読み込み | 通常の認証・権限確認通信失敗時にAB04と表示し、再確認を行う。 |
| ログアウト復旧領域 | AH02またはAH03と共通復旧操作。本文とヘッダーで同じ通知を二重表示しない。 |

- 未ログイン用リンク・権限回復時の商品一覧リンクは設けず、3章の自動遷移に統一する。
- 不正なURLや外部から渡された文言を、そのまま通知や戻り先に使用しない。

### 2.3 操作性

- 初回の表示確定時に見出しへフォーカスを移す。初回確認失敗時はエラー見出し等へ移す。
- タブ復帰・再確認のたびにはフォーカスを移さない。操作要素が消えた場合のみ適切な移動先を確保する。
- ボタン・リンクはキーボードで操作可能とし、処理中・失敗・状態変化は支援技術でも認識可能にする。
- 非活性制御はクリックとキーボードの双方に適用する。

## 3. 状態・遷移制御

### 3.1 通常の認証・権限確認

ログアウト開始前に適用する。開始後は3.2を優先する。

| 状態 | 表示・遷移 |
| --- | --- |
| 初回確認中 | 非リンクのロゴと「確認中…」。業務データ・導線は表示しない。 |
| 認証有効・管理者権限なし | 非リンクのロゴとログアウト。本文にAB01・AB02、ログアウト主操作、権限再確認を表示。 |
| 未ログイン・認証無効確定 | 以前の管理者戻り先をリセットし、SCA-01へ履歴置換。ログイン成功後はSCA-02。本画面・元の拒否画面を戻り先にしない。期限切れと判別できる場合のみAL08を引き継ぐ。 |
| 管理者権限確認済み | SCA-02の初期表示へ履歴置換。本画面に留める代替リンクは設けない。 |
| 確認通信失敗 | 非リンクのロゴ、AB04、「再読み込み」。権限不足・未ログインと断定しない。CMN-03のAH04と二重表示しない。 |

- CMN-03の確認処理を共有するが、SCA-07から同画面への再遷移を繰り返さない。
- 管理者認証が有効で管理者権限なしとAPIの結果種別で判別された場合に本画面を使用する。HTTP 403だけで一律に本画面へ送らない。
- 一般会員用プールの認証情報のみの場合は管理者認証成立と扱わず、共通認証の未ログイン・認証無効判定に従う。
- 今回は管理者権限そのものの不足を扱う。将来の機能別権限不足は、その機能と移動先の権限に応じて別途設計する。

### 3.2 ログアウト開始後

- ヘッダーと本文は同じログアウト処理・状態を共有する。開始前に両方を非活性にし、二重実行を防ぐ。
- 「権限を再確認」等の通常操作は停止し、CMN-03のログアウト・復旧制御を優先する。
- セッション終了が確認できた場合はSCA-01へ遷移しAH01を表示する。
- セッションが残っている、または確認できない場合はAH02またはAH03と復旧操作を表示する。権限ありと判定されてもSCA-02へ自動復帰しない。
- 「ログイン状態を再確認」はログアウト完了の確認であり、通常の「権限を再確認」と区別する。

### 3.3 データ・応答制御

- 権限喪失が確定した場合は、直前の業務データ・検索条件・入力キャッシュ・復元データを破棄する。
- 更新・キャンセル等のサーバー側の操作記録は削除しない。結果照会を再開する場合は、その時点の認証・権限検証に従う。
- 離脱前・管理者切替前・ログアウト開始前の古い応答で現在の表示や遷移判断を上書きしない。
- 本画面固有の未保存変更はない。通常の再確認で離脱確認を出さない。ログアウト中の操作抑止は共通仕様に従う。

## 4. アクション・イベント

### 4.1 初期表示・タブ復帰・再読み込み

1. ログアウト復旧中かを確認し、該当時は3.2を優先する。
2. 通常時はCMN-03と管理者認証・権限確認を共有して実行する。
3. 3.1に従い表示・遷移する。重複通信・二重通知を避ける。

### 4.2 権限を再確認

1. ボタンを非活性にし「確認中…」と表示する。二重要求を防ぐ。
2. 管理者認証・権限確認を実行する。権限不足の本文を残す場合も、現在再確認中であることを明示する。
3. 権限なしならAB01・AB02を維持してボタンを再活性化する。未ログイン・権限あり・通信失敗は3.1に従う。
4. 確認中にログアウトが開始された場合は、その確認応答による通常遷移を無効化してログアウト制御を優先する。

### 4.3 ログアウトして管理者ログイン画面へ

1. CMN-03の管理者ログアウト仕様を呼び出し、通常操作と両ログアウトボタンを停止する。「ログアウト中…」と表示する。
2. 現在のブラウザの管理者セッション終了を要求する。
3. 成功時は管理者側の認証情報・キャッシュと以前の戻り先を破棄し、SCA-01へ履歴置換してAH01を約3秒表示する。次回ログイン後はSCA-02へ進む。
4. 失敗・結果不明時は共通方式でセッション状態を確認する。終了済みなら成功時と同様に進む。
5. 終了未確認ならAH02またはAH03と「再度ログアウトを実行」、結果不明時は「ログイン状態を再確認」を表示する。
6. 共通ヘッダーからのログアウトも同じ手順を使用する。ユーザー側のセッション・カートや、他端末のセッションを本操作で変更しない。

## 5. 状態・メッセージ一覧

| ID | 状態 | 文言・操作 |
| --- | --- | --- |
| AB01 | 権限不足見出し | アクセス権限がありません |
| AB02 | 権限不足説明 | 現在のアカウントには、この管理画面へアクセスする権限がありません。権限のある管理者アカウントでログインし直してください。／「ログアウトして管理者ログイン画面へ」「権限を再確認」 |
| AB04 | 通常の認証・権限確認失敗 | 管理者のログイン状態を確認できませんでした。再読み込みしてください。／「再読み込み」 |

- AB03は未使用とし、IDを詰め直さない。
- ログアウト通知はCMN-03のAH01〜AH03、期限切れ案内はSCA-01のAL08を参照する。
- AH01：「管理画面からログアウトしました。」
- AH02：「ログアウト処理に失敗しました。もう一度お試しください。」
- AH03：「ログアウトが完了したか確認できませんでした。ログイン状態を再確認するか、もう一度ログアウトをお試しください。」
- 処理中：「確認中…」「ログアウト中…」。復旧操作：「ログイン状態を再確認」「再度ログアウトを実行」。
- 失敗通知は復旧するまで共通通知領域に残し、一時トーストのみとしない。

## 6. 画面で必要なAPI・共通連携項目

固有の業務APIは設けない。CMN-03共通の認証・権限確認と管理者ログアウトを使用する。URL・メソッド・物理項目名・型・結果コードはAPI設計で確定する。

### 6.1 管理者認証・権限確認

| 方向 | 項目 | 用途 |
| --- | --- | --- |
| 送信・付随 | 管理者セッション情報 | 管理者認証・権限確認。 |
| 受信 | 認証状態・管理者権限有無 | 権限不足表示、SCA-01／SCA-02への通常遷移、ログアウト復旧時の判断。 |
| 受信・認証時 | 管理者識別情報 | CMN-03との状態共有・管理者切替判定。 |
| 受信 | 処理結果・エラー種別・判別可能な期限切れ | 権限不足と他の拒否・通信失敗の区別、AB04・AL08判断。 |

### 6.2 管理者ログアウト

| 方向 | 項目 | 用途 |
| --- | --- | --- |
| 送信・付随 | 現在のブラウザの管理者セッション情報 | 対象セッションの終了。 |
| 受信 | 処理結果・エラー種別 | 終了確定、失敗、結果不明の分岐。 |

### 6.3 画面間の共通連携（API通信なし）

| 情報 | 用途 |
| --- | --- |
| 共通認証・権限確認結果 | 二重通信・通知、同一画面への再遷移を防止。 |
| ログアウト開始・処理中・結果不明・終了確定の状態 | ヘッダーと本文で二重実行を防ぎ、通常の権限回復遷移より復旧を優先。 |
| 以前の戻り先リセット・ログイン後SCA-02への遷移指定 | 権限不足画面や拒否された画面への再誘導を防止。 |
| AH01通知・判別可能な期限切れ通知 | SCA-01での表示。 |
