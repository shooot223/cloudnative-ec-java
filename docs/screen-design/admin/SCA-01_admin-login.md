# SCA-01: 管理者ログイン画面

## 1. 基本情報

- **物理名:** `admin-login`
- **対象:** 事前登録されたマスター管理者。
- **目的:** メールアドレス・パスワードによる認証と管理者権限確認を行い、管理画面へ案内する。
- **遷移先:** 有効な戻り先（SCA-02〜SCA-05）、未指定・不正時はSCA-02（商品管理一覧）。既存セッションの権限不足時はSCA-07。
- **共通画面:** CMN-03（管理者側共通レイアウト）、CMN-04（管理者側共通フッター）。
- **対象外:** 管理者登録・招待、パスワード再設定・初回変更、MFA、権限編集、ユーザー側カート統合の画面操作。
- **記載範囲:** 画面構成、入力・表示制御、操作、遷移、文言、画面で必要なAPI連携項目。アカウント初期作成、セッション有効期間、Cognito構成、権限検証方式は要件定義・共通認証設計で定義する。
- **認証連携の前提:** 管理者用Cognitoユーザープールを使用する。一般会員用プールとは分離し、利用者がプールを選択するUIは設けない。
- **文言:** 要件定義と同期し、API設計時に結果コード・表示条件との対応を確認する。文言IDはAPIコードではない。

## 2. 画面構成

### 2.1 共通レイアウト

- 上部にCMN-03、メインコンテンツの後にCMN-04を表示する。
- 本画面では業務ナビゲーション・ログアウトを非表示とする。ユーザー側の会員氏名・カートバッジは表示しない。
- フォームは中央に配置し、狭い画面では左右に余白を確保して縦1列とする。
- 見出しは「管理者ログイン」、補足は「管理者専用のログイン画面です。」とする。

### 2.2 フォーム

| 要素 | 表示・動作 |
| --- | --- |
| メールアドレス | ラベル付き入力欄。初期値は空。管理者の実際のメールアドレスを初期値・入力例として表示しない。 |
| パスワード | ラベル付き入力欄。初期値は空、伏字表示。入力文字を勝手に変更しない。 |
| パスワード表示切替 | 対象欄の伏字／平文を切り替える。ラベルは「パスワードを表示」／「パスワードを隠す」。フォーム送信を発生させない。 |
| ログインする | 入力を検証し、認証・権限確認を開始する。 |
| ショップトップ（商品一覧）へ戻る | SCU-01へ遷移する。 |
| 項目エラー領域 | 該当入力欄の近くにエラーを表示する。 |
| 全体通知領域 | 認証失敗、試行制限、期限切れ、通信失敗等をフォーム上部に表示する。 |
| ログイン状態を再確認 | ログイン結果不明時に表示する。ログイン処理を再送せず、現在の認証・権限状態を照会する。 |

- 新規登録・パスワード再設定・MFA設定へのリンクは設けない。
- 管理者は初期設定済みアカウントでログインする。本画面に確認メール送信・コード入力・再送の操作は設けない。一般会員登録の標準確認メールはSCU-04で扱う。
- ラベルと入力欄を関連付け、メール欄にはログインID用、パスワード欄には現在のパスワード用の自動入力属性を設定する。貼り付けを妨げない。
- 全操作をキーボードで実行可能とし、エラーは色だけで示さない。通知・処理状態は支援技術でも認識できるようにする。

## 3. 表示・入力制御

### 3.1 認証状態と戻り先

| 状態 | 表示・遷移 |
| --- | --- |
| 初回認証確認中 | 「確認中…」を表示し、フォームを表示しない。 |
| 未ログイン確定 | 空のフォームを表示する。 |
| 管理者としてログイン済み | 有効な戻り先、なければSCA-02へ履歴置換で遷移する。 |
| 既存の管理者側セッションに管理者権限がない | 業務画面を表示せずSCA-07へ遷移する。 |
| 認証確認失敗 | AL09と「再読み込み」を表示する。未ログインと断定しない。 |
| 管理者セッション期限切れ確定 | フォームとAL08を表示する。 |

- 戻り先はSCA-02〜SCA-05に対応する許可済みの内部パス・必要な識別情報のみ保持する。外部URL、ユーザー側画面、ログイン画面、未定義ルート等は採用せずSCA-02へ戻す。
- ユーザー側の認証状態やカートを、管理者側の認証判定に使用しない。
- 権限不足を示すAL05は管理者用プールでの認証成功後の権限判定結果に基づいて表示し、入力メールアドレスだけで判定しない。
- 一般会員用プールだけに存在するアカウントでのログイン試行は、管理者用プールでは認証失敗（AL04）として扱う。一般会員用プールへの照会・認証の切り替えは行わない。両プールに同じメールアドレスが登録されていても別アカウントとして扱う。

### 3.2 入力条件

| 項目 | 検証条件 | エラー |
| --- | --- | --- |
| メールアドレス | 前後空白除去後に必須、254文字以内、メールアドレス形式 | 未入力AL01、形式不正・超過AL02 |
| パスワード | 必須、空白のみ不可。文字列のトリム・変換は行わない | AL03 |

- ログイン時には登録時の最小文字数・文字種の組み合わせを再検証せず、認証結果で判定する。
- パスワードの入力上限は共通認証入力仕様で定義する。上限超過時はAL10を表示し、黙って切り詰めない。初期パスワードの登録上限と混同しない。
- 不正入力がある場合は認証APIを呼び出さない。

### 3.3 通信中・結果不明時

- ログイン・結果確認の通信中は入力欄、表示切替、ログインボタン、戻るリンク、CMN-03・CMN-04の遷移操作を非活性にする。
- 確認失敗で復旧操作を表示した後は再確認とショップへの遷移を可能にする。ただし、ログイン結果不明の間はログイン再送を許可しない。
- 試行制限中はログインボタンを非活性とし、API・共通認証仕様が示す再試行可能時刻・待機時間に従って解除する。未提供時の再試行間隔は共通仕様で定義する。
- パスワードは成功、失敗、結果不明、画面離脱時に消去し、伏字へ戻す。メールアドレスは同画面の再試行中のみ保持する。

## 4. アクション・イベント

### 4.1 初期表示

1. 戻り先情報を検証・保持し、管理者側の認証状態を確認する。
2. 3.1に従ってフォーム表示、遷移、エラー表示を行う。
3. 期限切れが確認済みの場合のみAL08を表示する。ログアウト完了通知はCMN-03の共通文言に従う。

### 4.2 ログインする／Enterキー

1. 日本語入力の変換確定中は送信しない。処理中・試行制限中・結果不明中の重複送信を防ぐ。
2. メールアドレスをトリムし、入力検証を行う。エラー時は該当欄に表示して最初のエラー項目へフォーカスを移す。
3. 操作を非活性にし、ボタンを「ログイン処理中…」へ変更する。
4. メールアドレス・パスワードを管理者ログインAPIへ送信する。認証先の管理者用プールはバックエンドの設定で決定する。
5. 認証成功かつ管理者権限ありの場合は、パスワードを消去し、共通認証方式でログイン状態を反映して有効な戻り先またはSCA-02へ履歴置換で遷移する。
6. 認証失敗はAL04、認証後の権限不足はAL05を本画面に表示する。権限不足時は管理機能を利用可能なセッションを成立させない。
7. 試行制限はAL06、失敗が確定したその他の通信・システムエラーはAL07を表示する。
8. 失敗時はパスワードを消去してメールアドレスを保持する。試行制限を除き再入力・再実行を可能にする。
9. 初回パスワード変更・MFA等の対象外の追加手続きが要求された場合は成功と扱わず、AL12を表示する。追加手続き用フォームは表示しない。

### 4.3 タイムアウト・通信切断で結果不明の場合

1. パスワードを消去し、ログインAPIは自動再送せず管理者認証状態を確認する。
2. 管理者ログイン成立が確認できれば、有効な戻り先またはSCA-02へ遷移する。
3. 未ログイン確定時はAL07とフォームを表示して再入力を可能にする。
4. 権限不足が確認できた場合はAL05を表示する。
5. 確認にも失敗した場合はAL11と「ログイン状態を再確認」を表示し、ログイン再送は停止する。
6. 再確認中は「確認中…」とし、二重照会を防ぐ。確認できるまで結果不明状態を成功・失敗に置き換えない。

### 4.4 ショップへ戻る・画面離脱

- 「ショップトップ（商品一覧）へ戻る」でSCU-01の初期表示へ遷移する。ユーザー側のログイン状態・カートは変更しない。
- 画面離脱時は入力パスワードとフォーム内エラーを破棄する。
- 古い応答や画面離脱後の応答で、現在のフォームや遷移先を上書きしない。
- 画面上の遷移抑止だけでブラウザ終了・戻る操作を完全には防げないため、復帰時は現在の認証状態を再確認する。

## 5. 状態・メッセージ一覧

| ID | 状態 | 表示文言・操作 |
| --- | --- | --- |
| AL01 | メール未入力 | メールアドレスを入力してください。 |
| AL02 | メール形式不正・上限超過 | 有効なメールアドレスを入力してください。 |
| AL03 | パスワード未入力・空白のみ | パスワードを入力してください。 |
| AL04 | 認証失敗 | メールアドレスまたはパスワードが正しくありません。 |
| AL05 | 認証後の管理者権限不足 | このアカウントには管理画面へのアクセス権限がありません。 |
| AL06 | 試行制限 | ログイン試行回数の上限に達しました。時間をおいて再度お試しください。 |
| AL07 | ログイン失敗確定 | ログイン処理に失敗しました。時間をおいて再度お試しください。 |
| AL08 | 管理者セッション期限切れ | 管理画面のログイン有効期限が切れました。再度ログインしてください。 |
| AL09 | 初回認証状態確認失敗 | ログイン状態を確認できませんでした。再読み込みしてください。／「再読み込み」 |
| AL10 | パスワード入力上限超過 | パスワードの入力可能な文字数を超えています。 |
| AL11 | ログイン結果不明・確認失敗 | ログインが完了したか確認できませんでした。ログイン状態を再確認してください。／「ログイン状態を再確認」 |
| AL12 | 対象外の追加認証手続きが必要 | この画面ではログイン手続きを完了できません。管理者アカウントの設定を確認してください。 |

- エラーは一時トーストだけにせず、フォーム内に表示する。状態解消・該当項目の再入力・再送信時に不要なエラーを解除する。
- 処理中のラベルは「ログイン処理中…」「確認中…」。
- 補足文言は「管理者専用のログイン画面です。」、主要操作ラベルは「ログインする」「ショップトップ（商品一覧）へ戻る」。

## 6. 画面で必要なAPI連携項目

以下は論理項目。URL・メソッド・物理名・型・結果コード、Cognitoとの通信・Cookie設定・トークン更新の内部方式はAPI設計・共通認証設計で確定する。ブラウザへCognitoトークンを直接返すことは必須としない。

### 6.1 管理者認証状態確認（初回・結果不明時・再確認）

| 方向 | 項目 | 用途 |
| --- | --- | --- |
| 送信・付随 | 管理者用のセッション情報 | 管理者側の現在の認証状態確認。ユーザー側セッションと区別する。 |
| 受信 | 認証状態・管理者権限判定結果 | 管理者ログイン済み、権限不足、未ログイン、確認できた期限切れの切り替え。 |
| 受信 | 処理結果・エラー種別 | 未ログイン確定と確認失敗の区別、AL09・AL11の表示。 |
| 受信・ログイン時 | 管理者識別情報・表示情報（表示名またはメールアドレス） | 共通状態の更新、CMN-03への連携。 |

### 6.2 管理者ログイン

| 方向 | 項目 | 用途 |
| --- | --- | --- |
| 送信 | メールアドレス | 認証対象の指定。 |
| 送信 | パスワード | 認証用。 |
| 受信 | 処理結果・エラー種別・管理者権限判定結果 | 成功、認証失敗、権限不足、試行制限、その他失敗の判定。 |
| 受信・必要時 | 追加手続きが必要であることを示す結果 | 対象外手続きを成功と扱わずAL12を表示する。内部の機密情報は返さない。 |
| 受信・試行制限時 | 再試行可能時刻または待機時間（提供できる場合） | 再送制御。未提供時は共通仕様に従う。 |
| 受信・成功時／付随 | 管理者セッション確立情報 | 共通のCookie方式で管理者ログイン状態を確立する。 |
| 受信・成功時 | 管理者識別情報・表示情報 | CMN-03の表示に使用する。 |

- 戻り先は画面間連携として保持する。APIへ渡す設計を採用する場合も、許可された管理者画面への遷移だけを認める。
- ゲストカート識別情報や会員カート情報は本画面の認証連携項目に含めない。
- 認証先プールIDや管理者権限フラグを、画面が任意に指定する入力項目として設けない。管理者用プール・アプリクライアントへの対応と権限はバックエンドで検証する。
- 本画面からメール送信APIは呼び出さない。標準確認メールの利用方針と購入完了メールの対象外方針は要件定義で扱う。
