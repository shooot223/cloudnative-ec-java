# CMN-03: 管理者側共通レイアウト

## 1. 基本情報

- **物理名:** `admin-common-layout`
- **対象・適用画面:** 管理者、SCA-01〜SCA-07。
- **目的:** 管理画面のヘッダー、商品管理・注文管理の導線、管理者表示、ログアウト、共通通知を提供する。
- **遷移先:** SCA-02（商品管理一覧）、SCA-04（注文履歴一覧）、SCA-01（管理者ログイン）。権限不足時はSCA-07。
- **連携:** CMN-04および画面本体と、認証確認結果・遷移許可状態・未保存変更の確認処理を共有する。
- **対象外:** ユーザー側への遷移リンク、カートバッジ、管理者アカウント追加・切替・編集、権限管理メニュー。
- **記載範囲:** 配置、表示、操作、遷移、文言、API・画面間連携項目。Cognitoプール分離、管理者セッション最大4時間、権限検証・失効の内部方式は要件定義・共通認証設計に従う。
- **文言:** 要件定義にも記載する。文言IDはAPIコードではなく、API設計時に結果コード・表示条件との対応を確認する。

## 2. 画面構成

### 2.1 配置

- ページ先頭に通常配置する。固定・スクロール追従は行わない。
- ヘッダー、共通通知領域、メインコンテンツの順に配置する。末尾のCMN-04とは共通の遷移許可状態を使用する。
- 768px以上は左側にロゴと業務ナビゲーション、右側に管理者表示とログアウトを配置する。
- 768px未満はロゴと「メニュー」開閉ボタンを配置し、業務ナビゲーション・管理者表示・ログアウトを開閉領域に表示する。表示対象の操作がない場合は開閉ボタンを表示しない。
- ヘッダー先頭に、フォーカス時に表示する「メインコンテンツへスキップ」リンクを設ける。

### 2.2 表示要素

| 要素 | 表示・動作 |
| --- | --- |
| ロゴ・タイトル | 「cloudnative-ec 管理画面」。管理者権限確認済みで通常遷移可能な場合はSCA-02の初期表示へのリンクとする。それ以外は非リンク表示。SCA-01では常に非リンクとする。 |
| 商品管理 | 権限確認済みの場合に表示し、SCA-02へ遷移する。SCA-02・SCA-03で現在の機能カテゴリであることを示す。 |
| 注文管理 | 権限確認済みの場合に表示し、SCA-04へ遷移する。SCA-04・SCA-05で現在の機能カテゴリであることを示す。 |
| 管理者表示 | 管理者権限確認済みの場合に「マスター管理者」と固定表示する。メールアドレス・氏名は表示しない。 |
| ログアウト | 管理者ログイン済み、または管理者側の認証は有効だが権限がない場合に表示する。現在のブラウザの管理者セッション終了を開始する。 |

- SCA-01では業務ナビゲーション・管理者表示・通常のログアウトボタンを表示しない。認証済みの場合の遷移はSCA-01のアクセス制御に従う。
- ユーザー側の商品一覧・ショップへのリンクは設けない。
- 表示名を権限の根拠にしない。管理者識別情報は同一管理者・セッション切替の判定に使用する。

### 2.3 モバイルメニュー・操作性

- 開閉ボタンは開閉状態と対象領域を支援技術へ通知する。
- 初期状態は閉じる。開閉ボタンからTabキーで表示中の操作へ移動できるようにする。閉じた領域内の操作にはフォーカスさせない。
- Escで閉じ、開閉ボタンへフォーカスを戻す。画面遷移時は閉じて遷移先のフォーカス制御に従う。
- 認証状態の変化で操作を取り除く場合は、見出しや復旧操作等へフォーカスを移し、消えた要素に残さない。
- 各操作をキーボードで実行でき、現在位置・処理中・エラーは色だけで表現しない。
- 非活性時はクリックとキーボードによる遷移を抑止し、支援技術にも操作不可を伝える。

### 2.4 共通通知領域

| 条件 | 表示・操作 |
| --- | --- |
| ログアウト成功 | SCA-01へ遷移後にAH01を約3秒表示する。 |
| ログアウト失敗確定 | AH02と「再度ログアウトを実行」。 |
| ログアウト結果不明 | AH03と「ログイン状態を再確認」「再度ログアウトを実行」。 |
| 通常の認証・権限確認の通信失敗 | AH04と「再確認」。画面本体に同じエラー・復旧操作がある場合はそちらを優先して二重表示しない。 |

- ログアウト復旧中の確認失敗にはAH03を用い、AH04を重ねて表示しない。
- エラーは一時トーストだけで済ませず、解消まで通知領域に表示する。
- 通知・結果更新・処理中状態は支援技術でも認識できるようにする。

## 3. 状態・操作制御

### 3.1 認証・権限状態

| 状態 | ヘッダーと本文の扱い |
| --- | --- |
| 初回確認中 | 非リンクのロゴと「確認中…」。管理者表示・業務ナビゲーション・業務データを表示しない。 |
| SCA-01表示中 | 非リンクのロゴ。フォームや認証エラー等はSCA-01で表示する。 |
| 管理者権限確認済み | ロゴ、商品管理、注文管理、「マスター管理者」、ログアウト。重要処理中等は操作を抑止する。 |
| SCA-07・認証有効／管理者権限なし | 非リンクのロゴとログアウト。業務ナビゲーション・管理者表示・業務データは表示しない。 |
| 認証・権限確認の通信失敗 | 非リンクのロゴと復旧操作。管理者情報・業務データを非表示とし、未ログインとは断定しない。 |
| ログアウト通信中 | 「ログアウト中…」。通常操作を抑止する。 |
| ログアウト未完了・結果不明 | 管理者情報・業務データを非表示にし、AH02またはAH03と復旧操作。通常の業務操作は再開しない。 |

- 復帰時の再確認中も認証が未確定の間は業務データを表示しない。未保存入力の保持・破棄は画面本体と共有する。
- 認証無効・権限喪失・管理者切替が確定した場合は、以前の管理データと復元用キャッシュを破棄する。

### 3.2 通常遷移と重要処理

- 商品登録・編集・削除、画像アップロード、注文更新・キャンセル、ログイン、ログアウト等の重要処理通信中は、ヘッダーとCMN-04の通常遷移・ログアウトを抑止する。
- 結果不明で復旧操作だけ許可されている場合も、通常遷移の抑止を継続する。結果確認ボタンが利用可能なことだけで解除しない。
- 画面本体が通常離脱を許可した場合に限り、共通の許可状態に従って解除する。
- 通常の一覧取得等の読み取り通信だけを理由に遷移を停止しない。ただし、認証・権限が未確定の場合は3.1を優先する。
- スキップリンクやメニューの開閉は画面離脱ではないため、通常の遷移抑止とは区別する。

### 3.3 未保存変更の確認

- SCA-03等の未保存変更がある画面からロゴ・業務ナビゲーション・ログアウトを実行する場合、画面本体と連携して破棄確認を表示する。
- 通常遷移の確認はAH05、ログアウトの確認はAH06とする。
- 初期フォーカスは「編集を続ける」。取消・Escでは操作を中止し、入力を保持する。
- 未保存変更がなければ確認ダイアログを表示しない。
- 通信中・結果不明で離脱が禁止されている場合は、破棄確認への同意だけで遷移や再送を許可しない。
- ブラウザ終了・戻る等の扱いは各画面の離脱制御に従い、ヘッダーで完全に防げることを前提にしない。

## 4. アクション・イベント

### 4.1 初期表示・画面遷移・タブ復帰・戻る操作

1. 管理者側の認証・権限状態を確認する。画面本体と結果・実行中の照会を共有し、同時の重複照会を避ける。
2. 確認中・成功・失敗に応じて3.1の表示へ切り替える。
3. SCA-02〜SCA-05で未ログイン・認証無効が確定した場合は業務データを破棄し、現在の有効な管理画面を戻り先としてSCA-01へ遷移する。期限切れと判別できる場合のみAL08を引き継ぐ。
4. 保護画面で認証有効・権限不足が判明した場合は、業務データを破棄してSCA-07へ遷移する。
5. SCA-01は自身のアクセス制御、SCA-06・SCA-07は各画面のアクセス制御を優先し、共通レイアウトだけで一律リダイレクトしない。SCA-07からSCA-07への遷移を繰り返さない。
6. 通信失敗はAH04と「再確認」、または画面本体の認証確認エラーを表示する。

- 管理者側の認証情報だけを確認対象とする。ユーザー側のログイン状態を代用しない。
- ログアウト後・管理者切替後・画面離脱後の古い応答で表示や遷移先を上書きしない。

### 4.2 ロゴ・商品管理・注文管理

1. 権限確認済みかつ通常遷移可能であることを確認する。
2. 未保存変更があればAH05で確認し、「変更を破棄して移動する」を選択した場合のみ移動する。
3. ロゴ・商品管理はSCA-02、注文管理はSCA-04の初期表示へ遷移する。同じ一覧を表示中の場合も検索条件・取得位置を初期状態に戻す。
4. モバイルメニューは閉じる。

### 4.3 管理者ログアウト

1. 重要処理等により操作が禁止されていないことを確認する。
2. 未保存変更がある場合だけAH06を表示する。「編集を続ける」では処理を開始しない。「変更を破棄してログアウト」を選択した場合は入力を破棄して開始する。
3. 「ログアウト中…」を表示し、通常の画面操作・重複実行を抑止する。現在のブラウザの管理者セッション終了を要求する。
4. 成功時は管理者の認証・表示データ、入力キャッシュ、復元用データを破棄する。履歴置換でSCA-01へ遷移し、AH01を約3秒表示する。
5. 失敗・結果不明時は管理者情報・業務データを非表示にし、認証状態を再確認する。
6. セッション無効が確認できれば成功時と同様に処理する。有効なまま失敗が確定した場合はAH02、確認できなければAH03を表示する。
7. 「ログイン状態を再確認」は状態照会だけを行う。「再度ログアウトを実行」は同じブラウザの管理者セッション終了を再要求する。復旧通信中は各ボタンを非活性にする。

- ログアウト復旧中にセッションが有効と判明しても、業務画面へ自動復帰しない。
- ユーザー側のセッション・カートおよび他端末の管理者セッションを終了しない。
- 登録・更新・キャンセル等の結果確認に必要なサーバー側の操作記録を、ログアウトやクライアントキャッシュの破棄に伴って削除しない。
- ブラウザの戻る操作でも、認証・権限の再確認前に以前の管理データを表示しない。

### 4.4 認証状態の再確認

- 「再確認」押下時は「確認中…」と表示し、二重照会を防ぐ。
- 成功時は現在の認証・権限に従って表示・遷移し、AH04を解除する。失敗時は案内と再確認操作を残す。
- ログアウト復旧中は4.3の制御を優先する。

## 5. 状態・メッセージ一覧

| ID | 状態 | 文言・操作 |
| --- | --- | --- |
| AH01 | ログアウト成功 | 管理画面からログアウトしました。 |
| AH02 | ログアウト失敗確定 | ログアウト処理に失敗しました。もう一度お試しください。／「再度ログアウトを実行」 |
| AH03 | ログアウト結果不明 | ログアウトが完了したか確認できませんでした。ログイン状態を再確認するか、もう一度ログアウトをお試しください。／「ログイン状態を再確認」「再度ログアウトを実行」 |
| AH04 | 認証・権限確認の通信失敗 | 管理者のログイン状態を確認できませんでした。／「再確認」 |
| AH05 | 未保存変更がある場合の画面遷移 | 保存されていない変更があります。変更を破棄して移動しますか？／「編集を続ける」「変更を破棄して移動する」 |
| AH06 | 未保存変更がある場合のログアウト | 保存されていない変更があります。変更を破棄してログアウトしますか？／「編集を続ける」「変更を破棄してログアウト」 |

- 固定表示：「cloudnative-ec 管理画面」「マスター管理者」。
- 操作ラベル：「商品管理」「注文管理」「ログアウト」「メニュー」「メインコンテンツへスキップ」。
- 処理中：「確認中…」「ログアウト中…」。
- 期限切れはSCA-01のAL08「管理画面のログイン有効期限が切れました。再度ログインしてください。」を引き継ぐ。
- AH05・AH06は画面本体と共通化し、同じ操作に対して二重に確認しない。

## 6. 画面で必要なAPI・共通連携項目

以下は論理項目。URL・メソッド・物理名・型・結果コードはAPI設計で確定する。認証確認はSCA-01および画面本体と共通化する。

### 6.1 管理者認証・権限確認

| 方向 | 項目 | 用途 |
| --- | --- | --- |
| 送信・付随 | 管理者用セッション情報 | 管理者側の現在の認証・権限確認。 |
| 受信 | 認証状態・管理者権限有無 | メニュー表示、未ログイン・権限不足の区別。 |
| 受信 | 処理結果・エラー種別・判別可能な期限切れ情報 | 通信失敗との区別、再確認・AL08表示。 |
| 受信・認証時 | 管理者識別情報 | 同一管理者判定・管理者切替時のキャッシュ破棄。 |

- 表示は「マスター管理者」固定のため、氏名・メールアドレスを本ヘッダーの表示に必須の応答項目としない。
- 一般会員用プールの認証情報を受け入れず、認証先と権限はバックエンドで検証する。

### 6.2 管理者ログアウト

| 方向 | 項目 | 用途 |
| --- | --- | --- |
| 送信・付随 | 現在のブラウザの管理者用セッション情報 | 終了対象の特定。 |
| 受信 | 処理結果・エラー種別 | 成功・失敗の表示分岐。通信切断等は結果不明として状態照会する。 |

- 対象セッションが既に終了している場合も、終了済みとして復旧を完了できるようにする。
- 管理者認証情報をユーザー側ログアウトや全端末ログアウトへ流用しない。

### 6.3 画面間の共通連携（API通信なし）

| 情報 | 用途 |
| --- | --- |
| 現在画面・機能カテゴリ・有効な戻り先 | メニュー強調、認証後の復帰、SCA-06・SCA-07との制御分担。 |
| 認証・権限状態および確認中の処理 | 同じ照会の重複実行・エラー二重表示を防ぐ。 |
| 通常遷移の許可状態・重要処理中・結果不明 | CMN-04・画面本体と操作抑止を共有。 |
| 未保存変更の有無・離脱確認の結果 | ナビゲーション・ログアウト時の破棄確認。 |
| ログアウト処理・復旧状態・完了通知 | AH01〜AH03の表示と復旧操作。 |
| 管理者・セッション・画面の切替を識別する情報 | 古い応答による表示復元を防止する。 |
