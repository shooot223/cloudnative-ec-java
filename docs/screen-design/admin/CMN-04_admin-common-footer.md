# CMN-04: 管理者側共通フッター

## 1. 基本情報

- **物理名:** `admin-common-footer`
- **対象:** 管理者（未ログイン・認証確認中・権限不足を含む）。
- **適用画面:** SCA-01〜SCA-07。
- **目的:** 管理者向け全画面の末尾にコピーライトを表示する。
- **遷移先:** なし。
- **配置連携:** CMN-03・各管理画面と共通のページ構造を構成する。認証状態・重要処理中・遷移抑止の状態連携は行わない。
- **対象外:** ユーザー側トップへのリンク、管理画面内のナビゲーション、ログアウト、その他のリンク・ボタン。
- **記載範囲:** 配置、表示、状態別の扱い、文言、API連携の有無。
- **文言:** 要件定義にも同一文言を記載する。文言IDは資料間の参照用であり、APIコードではない。

## 2. 画面構成

### 2.1 配置

- 各画面のメインコンテンツの後に通常配置する。固定表示・スクロール追従は行わない。
- 内容が少ない画面でも、ページ全体の最小高さを表示領域に合わせ、メイン領域の余白によってフッターを表示領域の下部に配置する。
- 内容が長い画面では本文の末尾に配置し、ページ全体のスクロールで到達できるようにする。
- 本文・操作要素にフッターを重ねない。
- コピーライトは中央寄せを基本とし、左右に余白を確保する。狭い画面や文字拡大時には折り返し、横方向のはみ出しを防ぐ。

### 2.2 表示要素

| 要素 | 表示・動作 |
| --- | --- |
| コピーライト | AF01を非リンクのテキストとして表示する。年は2026に固定し、自動更新しない。 |

- コピーライト以外のリンク・ボタンは設けない。
- ユーザー側の商品一覧・ショップへの導線を表示しない。
- フッターをページ末尾の領域として支援技術が認識できるようにする。
- コピーライトに不要なTabフォーカス、リンク用カーソル、クリック操作を付けない。

## 3. 表示・状態制御

- 未ログイン、認証確認中、ログイン済み、権限不足、認証確認失敗、本文の取得失敗、各種処理中のいずれでも同じコピーライトを表示する。
- フッター表示は認証確認やAPI応答を待たない。
- 操作要素がないため、重要処理中の非活性化・遷移抑止は行わない。
- ローディング、エラー、成功通知、再試行操作は本フッターに設けない。画面本体またはCMN-03で扱う。
- フッター固有のアクション・イベントは設けない。

## 5. 画面で必要なAPI・共通連携項目

- 本コンポーネント固有のAPI通信はない。
- 認証状態・管理者情報・権限を取得するAPIは呼び出さない。
- 重要処理中・未保存変更・遷移抑止等の状態を受け取る必要はない。
- 表示は固定文言と共通レイアウトの配置だけで完結する。
