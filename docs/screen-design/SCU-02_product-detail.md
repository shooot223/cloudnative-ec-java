# SCU-02: 商品詳細画面

## 1. 基本情報

- **物理名:** `product-detail`
- **対象:** ユーザー（非会員・ゲストユーザーを含む）
- **目的:** 商品の画像・概要・詳細説明・税込価格・販売状態を確認し、数量を指定してカートに追加する。
- **主な遷移先:** 商品一覧画面（SCU-01）、カート画面（SCU-06）
- **利用する共通画面:** CMN-01（ユーザー側共通レイアウト）、CMN-02（ユーザー側共通フッター）、SCU-10（存在しないページの警告）相当の共通表示
- **記載範囲:** 画面構成、表示・入力制御、操作、状態別メッセージ、画面で必要なAPI連携項目。カートの保存方式・有効期限・在庫判定の内部処理は共通仕様・機能設計で定義する。

## 2. 画面構成

### 2.1 共通エリア

- 画面上部にCMN-01を表示する。
- カートアイコン押下時はSCU-06へ遷移する。
- カートバッジは全商品の数量合計を表示する。合計0の場合は非表示、100以上の場合は「99+」とする。
- カート情報が取得できない場合は数量不明として扱い、0件と断定する表示は行わない。商品詳細の閲覧は継続できる。

### 2.2 商品一覧への導線

- 「商品一覧へ戻る」リンクを表示する。
- SCU-01から遷移してきた場合は、可能な範囲で検索条件・取得済み商品・スクロール位置を復元する。
- 復元できない場合や直接アクセスした場合はSCU-01の初期表示へ遷移する。

### 2.3 商品情報エリア

- 768px以上では画像を左側、商品情報・操作エリアを右側に配置する。
- 768px未満では画像、商品情報、操作エリアの順で縦に配置する。
- 商品概要と詳細説明は別の見出し・領域で表示する。

| 要素 | 表示・動作仕様 |
| --- | --- |
| 商品ID | URL等から取得し、詳細取得・カート追加の識別情報として保持する。画面には表示しない。 |
| 商品画像 | APIから取得した画像URLを使用する。縦横比を保持して所定領域に表示し、商品名などの代替テキストを設定する。 |
| 代替画像 | 画像URL未設定・取得失敗時はNo Image画像に切り替える。切り替えを繰り返さない。 |
| 商品名 | 省略せず全文を表示する。 |
| 税込価格 | APIから受け取った税込価格を円単位・小数なし・3桁区切りで表示する。例：「￥1,980（税込）」。 |
| 販売状態 | 「在庫あり」「売り切れ」「現在購入できません」のいずれかを表示する。判定と操作可否は3章に従う。 |
| 商品概要 | 省略せず全文をテキストとして表示し、改行を保持する。未設定時は「商品概要はありません。」と表示する。 |
| 詳細説明 | 省略せず全文をテキストとして表示し、改行を保持する。未設定時は「詳細説明はありません。」と表示する。 |

### 2.4 カート操作エリア

| 要素 | 表示・動作仕様 |
| --- | --- |
| 数量入力欄 | 数値入力欄。初期値は1とし、カートに追加する数量を入力する。入力条件は3.2に従う。 |
| 減算ボタン | 数量を1減らす。数量が1の場合は非活性とする。 |
| 加算ボタン | 数量を1増やす。数量が表示上の在庫数に達している場合は非活性とする。 |
| カートに追加ボタン | 指定した数量の追加処理を開始する。 |
| カートを見るリンク | SCU-06へ遷移する。通知とは別に操作エリアに表示する。 |
| エラー表示領域 | 数量エラーは入力欄付近、追加処理のエラーは操作エリアに表示する。色だけで状態を表現しない。 |

- 入力欄には「数量」、増減ボタンには「数量を減らす」「数量を増やす」などの識別可能な名前を設定する。
- リンク・入力・増減・追加操作はキーボードでも操作できること。
- 成功通知・エラー通知は支援技術でも認識できるようにする。

### 2.5 フッター

- メインコンテンツの後にCMN-02を表示する。

## 3. 表示・入力制御

### 3.1 販売状態と操作可否

| 商品の状態 | 表示 | 数量入力・増減・追加ボタン |
| --- | --- | --- |
| 公開・販売可能で在庫数が1以上 | 在庫あり | 表示する。 |
| 公開・販売可能で在庫数が0 | 売り切れ | 非表示にする。 |
| 公開中だが販売停止等で購入不可 | 現在購入できません | 非表示にする。 |
| 在庫数・販売可否が欠損または不正 | 現在購入できません | 非表示にする。 |
| 商品IDが未指定・不正、または商品が存在しない・非公開・削除済み | SCU-10相当の共通表示 | 商品詳細とカート操作を表示しない。 |

- 購入不可の状態を在庫数による表示より優先する。
- SCU-10相当の表示に切り替える際は取得済みの商品詳細も取り除き、SCU-01への導線を表示する。具体的な警告文はSCU-10に統一する。
- 通信障害は「商品が存在しない」と区別して表示する。

### 3.2 数量入力

- 必須入力とし、1以上かつ画面が保持する在庫数以下の整数を受け付ける。
- 空欄・0・負数・小数・数値以外の場合は「数量は1以上の整数で入力してください。」と表示する。
- 表示上の在庫数を超える場合は「在庫数以下の数量を入力してください。」と表示する。
- 不正な入力のままカート追加APIを呼び出さない。不正値を自動で切り捨てて送信しない。
- 入力値が不正な間は増減ボタンを非活性とし、数値入力欄での修正を受け付ける。
- 最新在庫数が入力数量を下回った場合は数量を自動で変更せず、エラーを表示して修正を促す。在庫0・販売不可になった場合は3.1の表示へ切り替える。
- 画面に表示されている在庫数は入力補助に使用する。追加の最終可否はAPIの応答に従う。

## 4. アクション・イベント

### 4.1 初期表示

1. 対象の商品IDを取得する。未指定または形式不正の場合はSCU-10相当の表示に切り替える。IDの形式はAPI設計で定義する。
2. 商品詳細を取得し、取得中は商品情報エリアにローディング表示を出す。
3. カート合計数量を取得し、共通ヘッダーのバッジを更新する。商品詳細取得とは独立して結果を反映する。
4. 商品詳細取得成功時は商品情報と状態に応じた操作を表示する。
5. 商品が存在しない・非公開・削除済みの場合はSCU-10相当の表示に切り替える。
6. 商品詳細取得の通信失敗時はエラーと「再読み込み」ボタンを表示する。再読み込みでは同じ商品IDで再取得する。
7. 画面離脱後や別商品への切り替え前に開始された古い応答が、現在の表示を上書きしないようにする。

### 4.2 カートに追加

1. 数量を検証し、エラーがあれば通信せず入力欄付近に表示する。
2. 送信時の数量を保持し、数量入力・増減・追加ボタンを非活性にする。追加ボタンに処理中の表示を出し、重複送信を防ぐ。
3. 商品IDと追加数量をカート追加APIに送信する。
4. **成功時:** 「カートに追加しました」という通知を3秒表示し、APIが返すカート合計数量でバッジを更新する。画面遷移は行わず、入力数量は保持する。
5. **明確な失敗時:** 理由に応じたエラーを操作エリアに表示する。成功通知や数量バッジの加算は行わない。
6. 成否にかかわらず最新の商品情報が返された場合は、販売状態・在庫情報に反映する。数量が最新在庫を超える場合は修正を促す。
7. 非公開・削除済み・不存在が判明した場合はSCU-10相当の表示に切り替える。
8. 結果が確定した後は最新状態に応じて操作可否を更新する。

### 4.3 追加結果が不明な場合

- タイムアウト・通信切断等で追加結果を判定できない場合は「追加結果を確認できませんでした。カートの内容をご確認ください。」と表示する。
- 自動で追加処理を再送しない。「カートを見る」からSCU-06へ移動できるようにする。
- カート情報を再取得できた場合はバッジを更新する。ただし、合計数量のみで今回の追加成功を断定しない。
- 結果不明時は追加ボタンを非活性のままとし、カートでの確認を案内する。結果照会・同一操作の再送可否は共通カート機能設計で定義する。

## 5. 状態・メッセージ一覧

| 状態 | 表示・動作 |
| --- | --- |
| 商品詳細取得中 | 商品情報エリアにローディング表示を出す。 |
| 商品が存在しない・非公開・削除済み／商品ID未指定・不正 | SCU-10相当の共通表示に切り替え、SCU-01への導線を表示する。 |
| 商品詳細取得失敗 | 「商品情報の取得に失敗しました。」と「再読み込み」ボタンを表示する。 |
| カート合計数量取得失敗 | 商品詳細は表示し、バッジは数量不明として扱う。カート取得失敗の案内と再取得操作はCMN-01の共通仕様に従う。 |
| 数量不正 | 「数量は1以上の整数で入力してください。」と表示する。 |
| 数量が表示在庫を超過 | 「在庫数以下の数量を入力してください。」と表示する。 |
| 追加処理中 | 数量入力・増減・追加を非活性にし、追加ボタンに処理中の表示を出す。 |
| 追加成功 | 「カートに追加しました」と表示し、カート合計数量を更新する。 |
| 在庫不足 | 「カート内の数量を含めると在庫数を超えるため、追加できません。数量またはカートの内容をご確認ください。」と表示する。最新在庫があれば反映する。 |
| 公開中の商品が販売不可に変化 | 「この商品は現在カートに追加できません。」と表示し、販売状態を更新する。 |
| 追加失敗が確定したその他のエラー | 「カートに追加できませんでした。時間をおいて再度お試しください。」と表示する。 |
| 追加結果不明 | 「追加結果を確認できませんでした。カートの内容をご確認ください。」とSCU-06への導線を表示する。 |
| 画像取得失敗 | 対象画像のみNo Imageに切り替える。画面全体をエラーにしない。 |

- 操作エラーは一時的な通知だけにせず、操作エリアに表示する。再操作・修正・状態更新に応じて不要なエラーを解除する。

## 6. 画面で必要なAPI連携項目

以下は画面で必要な論理項目。エンドポイント、物理項目名、型、認証・ゲスト識別の受け渡し、エラーコードはAPI設計で確定する。

### 6.1 商品詳細取得

| 方向 | 項目 | 画面での用途 |
| --- | --- | --- |
| 送信 | 商品ID | 対象商品の指定。 |
| 受信 | 商品ID | 表示対象の識別、カート追加時の指定。 |
| 受信 | 商品名 | 商品名・画像の代替テキスト表示。 |
| 受信 | 商品概要 | 概要エリアへの全文表示。 |
| 受信 | 詳細説明 | 詳細説明エリアへの全文表示。 |
| 受信 | 画像URL | 商品画像表示。未設定を判別できること。 |
| 受信 | 税込価格 | 価格表示。画面で税率を掛けて再計算しない。 |
| 受信 | 在庫数 | 在庫状態表示、数量入力・増減の上限制御。 |
| 受信 | 販売可否・購入不可理由 | 売り切れと販売停止等の区別、操作可否の制御。 |
| 受信 | 取得結果・エラー種別 | 表示可能、SCU-10相当表示、通信エラーの切り替え。非公開・削除済みの内部的な区別を画面に開示する必要はない。 |

### 6.2 カート合計数量取得

| 方向 | 項目 | 画面での用途 |
| --- | --- | --- |
| 送信・付随 | 会員の認証情報、またはゲストカートの識別情報 | 対象カートの特定。共通方式を使用する。 |
| 受信 | カート内合計数量 | 初期表示・結果確認時のヘッダーバッジ更新。 |
| 受信 | 取得結果・エラー種別 | 正常な0件と取得失敗の区別。 |

### 6.3 カート追加

| 方向 | 項目 | 画面での用途 |
| --- | --- | --- |
| 送信・付随 | 会員の認証情報、またはゲストカートの識別情報 | 対象カートの特定。共通方式を使用する。 |
| 送信 | 商品ID | 追加対象の指定。 |
| 送信 | 追加数量 | 現在のカート数量への加算数。更新後の総数量とは区別する。 |
| 受信 | 処理結果・エラー種別 | 成功、在庫不足、販売不可、対象なし等の表示切り替え。 |
| 受信 | カート内合計数量 | 成功時のヘッダーバッジ更新。 |
| 受信 | 最新の在庫数 | 取得できる場合に販売状態・数量上限を更新する。 |
| 受信 | 最新の販売可否・購入不可理由 | 取得できる場合に購入操作の可否を更新する。 |
| 受信 | 商品詳細の表示可否を判断できる結果 | 非公開・削除済み等になった場合のSCU-10相当表示への切り替え。 |

- 追加結果不明時の照会や再送に操作識別子等が必要な場合は、共通カート機能設計・API設計で追加定義する。
